외부 API 테스트

GET /api/ask 로 질문을 보냅니다. WAIT=N(기본)이면 즉시 "생성중" 응답과 결과 JSON URL 을 돌려주고, 결과는 자동으로 가져와 표시합니다. WAIT=Y 면 답변이 끝날 때까지 기다렸다가 최종 결과를 바로 반환합니다. 키가 호출자 JSON을 수락하면, 그 요청에 붙인 schema / rule 형식으로만 답합니다. JSON 결과 설정에 고른 항목은 그 한 건에는 쓰지 않습니다. 기억 테스트는 U_ID(장기) / S_ID(단기)를 넣고 WAIT=Y로 연속 호출하는 편이 쉽습니다.

기억 기능 빠른 테스트

  1. 단기(S_ID): 같은 S_ID로 「내 이름은 민수야」→「내 이름이 뭐야?」 (클라이언트 HISTORY 없이 서버 세션이 이어짐)
  2. 장기(U_ID): 같은 U_ID로 「나 파이썬 좋아해」보낸 뒤, S_ID만 새로 만들기 「내가 뭐 좋아한다고 했지?」 → 세션이 바뀌어도 회상
  3. 둘 다 비우면 기억 비활성(기존 외부 API와 동일)
